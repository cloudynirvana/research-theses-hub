## Google Scholar / ResearchGate (later, manual)

Do this as the account owner. This hub cannot mint Scholar entries.

1. Keep the GitHub full text public and crawlable.
2. When a stable HTML landing page and PDF exist for a thesis, add
   Highwire `citation_*` tags in that source repo (already sketched in
   `project-confluence` `docs/SCHOLAR_INDEXING.md` and
   `complexity-science` `docs/SCHOLAR_THESIS_02.md`).
3. Create or update a Google Scholar profile named **exactly**
   Kelechi Emeka Ogbonna. Homepage: this hub and/or GitHub
   `cloudynirvana`. Use the personal mailbox until an institutional
   email exists.
4. After a record appears, **confirm** it. Do not write clinical, dosing,
   or CDS language in profile or abstract fields.
5. ResearchGate: add the GitHub URL and PDF as a preprint/technical
   report only if the abstract stays research-only. Do not mark the work
   as a peer-reviewed article unless that is true.
6. First Scholar coverage is often days to weeks; updates to an already
   indexed paper can take many months. Inclusion is not guaranteed and
   is not peer review.
